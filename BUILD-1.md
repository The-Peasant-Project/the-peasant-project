# BUILD 1 — the only thing for the next three months

**One person, one server, one real business.** Rob is the person. FatNumbat Media — Rob's own creative business (music and art prints) — is customer one. The server is a single rented VPS from an Australian provider (not a hyperscaler; Binary Lane suggested, about AUD 10 to 15 a month).

The point of Build 1 is not to prove the idea in the abstract. It is to have one working example we can point at, and a set of notes honest enough to become the guides.

## Done means

- [ ] The Peasant Project site is served from that server. GitHub is demoted to a mirror.
- [ ] FatNumbat's website, shop, email and files are running on the bundle.
- [ ] A written before-and-after: what FatNumbat paid, to how many companies; what it pays now, to whom.
- [ ] An export that actually works: everything moved to a second server (a temporary one is fine) and back, timed.
- [ ] Backups offsite, tested by restoring once.
- [ ] Notes kept throughout, because they become the guides.

## Open deliberation, to be settled by doing

Coop Cloud versus assembling our own from containers. Try Coop Cloud first for a weekend on this server. See [`deliberations/2026-09-04-build-on-coop-cloud.md`](deliberations/2026-09-04-build-on-coop-cloud.md).
