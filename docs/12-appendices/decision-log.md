# Decision log

2026-09-04. Name: Understory. Reason: community, earth, connection, the layer beneath the canopy. Alternatives considered: Hearth, Commonweal, Tend, Kin.
2026-09-04. Licences: CC BY-SA 4.0 for documents, AGPL-3.0 for code. Reason: defensive openness.
2026-09-04. Pathway: individuals first, town shape emerges. Reason: cannot assume town adoption; shape must stay open.
2026-09-04. Heat to homes out of scope at outset. Reason: distribution cost; put compute at the heat load instead.
2026-09-04. Umbrella name: The Peasant Project. Understory remains the name of the compute network and protocol within it. Signed: Rob.
2026-09-04. Monorepo. Reason: solo founder, agents work best with one context, consistency checking needs everything in one place. Split only on separate release cadence or contributors. Signed: Rob.
2026-09-04. Borrowed scaffolding: GitHub, Codespaces and commercial models used in the interim, with a Codeberg mirror from day one and self-hosting when there is a node to host on. Qualm filed in inbox. Signed: Rob.
2026-09-04. Rule changes only via deliberation and decision log; applies to founder, oracle and any agent. Reason: prevents the keyboard-holder becoming the lord. Signed: Rob.
2026-09-04. House style for all explainers and primers is guides/explainer.md. Signed: Rob.
