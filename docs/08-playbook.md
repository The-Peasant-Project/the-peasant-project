# The playbook

Intended content: checklist for one person (hardware, power, install, first buyer); checklist for two to ten (group creation, constitution adoption, first dividend); checklist for a registered co-operative (Australian state co-operative registration, site lease, insurance); checklist for a public site host (councils, pools, aged care); templates for constitution, host agreement, site lease, and the network entity's guardian rules.
