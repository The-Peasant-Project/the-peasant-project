# Licence note

Documents are CC BY-SA 4.0. Code is AGPL-3.0.

This is a defensive choice. Anyone may copy, run, and change Understory. Anyone who offers it as a service must publish their changes. A large company can adopt it, but cannot enclose it. Combined with the reciprocity rule in Part 07, that means the only way to profit from a fork at scale is to feed the pool. Openness is the moat, and appeal is the lock.

If a future decision log entry moves the code to a different copyleft licence, this note should say why.
