# The Peasant Project

A kit that lets one competent person run the everyday online tools their neighbours already pay for, as a co-op they can't take over.

The kit is three things:

- **A software bundle.** Websites, bookings, email, files. One login, one bill, an export button. All on one server.
- **A playbook.** How twenty customers become a co-op with fair rules.
- **The guides.** The ladder that turns a curious person into someone who can run the server.

Software, rules, teaching. Nothing else is the product.
