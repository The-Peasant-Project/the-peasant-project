# The Peasant Project

Tools, rules and know-how for ordinary people to own the machinery they are currently renting from digital lords, and to share what it earns.

The first piece is Understory: a protocol and playbook for small, community-owned compute networks that run on wasted renewable energy, put their heat where it is wanted, and pay an equal dividend to every member. Understory is a protocol, not a platform. The Peasant Project is the umbrella for that and whatever comes next: the learning resources, the deliberations, the legal templates, the philosophy.

It starts with one person and one machine. It does not need permission.

## Layout

```
docs/           the Understory playbook, plain to technical (see INDEX.md)
learning/       explainers built with guides/explainer.md, one idea each
guides/         house style: how we explain, how we deliberate, how we decide
inbox/          qualms, questions and ideas, one file each, triaged by the oracle
deliberations/  hard questions worked over by several models and people
src/            code: understory-scheduler, understory-ledger, more later
scripts/        build_index.py, consistency_check.py
.devcontainer/  one environment for Codespaces, a VPS, or your own machine
.github/        actions: index rebuild, consistency check, mirror to Codeberg
```

## Where this is hosted, and why

On GitHub for now, mirrored automatically to Codeberg. We are using the lords' scaffolding to build the thing that makes it unnecessary, and the mirror is the exit. See the decision log.
