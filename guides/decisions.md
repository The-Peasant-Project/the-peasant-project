# How a rule changes

A rule is anything in `AGENTS.md` under design constants, anything in Part 01 principles, or any mechanism in Part 03.

To change one: open a deliberation, run it per `guides/deliberation.md`, append an entry to `docs/12-appendices/decision-log.md` with the date, the decision, the reason, and who signed it, then and only then edit the documents. The consistency check will refuse a rule change that has no matching decision log entry.

This applies to the founder. It applies to the oracle. It applies to a coding agent that thinks it has found a better way.
